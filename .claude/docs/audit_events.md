# Audit trail contract (`audit_log`, schema_version 1)

Language-neutral: PHP (today) and the Rust/Tauri backend (future) write and read the SAME table with the SAME rules.

## Write rules
1. **One INSERT per event, inside the caller's DB transaction** (commit/rollback with the business action; in retry loops write it INSIDE the retried closure). Never open a transaction for it.
2. **Fail-closed** for money/stock/config changes (audit failure aborts the action). **Best-effort** for login/logout/denied.
3. Append-only: nothing in the app updates or deletes rows.
4. `occurred_at` is **UTC** `DATETIME(3)`; viewers convert to America/Managua. `request_id` is generated by the caller (PHP: random hex; clients may send header `X-Request-Id` `[A-Za-z0-9_-]{8,40}`) and shared by every row of one request. `terminal_id` comes from header `X-Terminal-Id` (Tauri terminals); otherwise the IP identifies the device.
5. Actor = the shared session contract (`ci_sessions`: `id_admin`, `admin_name`, `role`); name and role are **snapshotted** in the row. Never store passwords/hashes (`pass*`/`*hash*` keys are stripped by `Audit::change`).
6. `before`/`after`: JSON objects, only what matters (diff of changed columns for edits; full snapshot for creates; ids of affected child rows for merges/splits/deletes). Max 60 000 bytes, larger payloads are replaced by `{"truncated":true,"bytes":N}`. 4-byte UTF-8 chars are replaced by `?` (the app connection is utf8mb3).
7. `source`: `php` | `rust` | `tauri`.

## Columns
`id`, `schema_version`, `occurred_at`, `request_id`, `source`, `id_admin`, `admin_name`, `role`, `ip`, `terminal_id`, `user_agent`, `request` (`controller/method` or route), `action`, `result` (`ok|denied|error`), `entity_type`, `entity_id`, `id_tab`, `id_bill`, `id_sale` (context ids for timelines), `summary` (Spanish one-liner), `before_json`, `after_json`. DDL: `migrations/restaurant_022_audit_log.sql`. JSON Schema of the API event: `docs/audit_event.schema.json`.

## PHP entry points
`$this->audit->log($action, $entity_type, $entity_id, array(before, after, tab, bill, sale, summary, result, actor, best_effort))`, `->change(...)` (diff of two rows, no row when nothing changed), `->denied(...)`, `->row($table,$pk,$id)`. Library: `application/libraries/Audit.php` (autoloaded). Read side: `Audit_mdl`, screen `/audit`, controller `Audit_trail` (routed from `/audit/...`).

## Actions (`action`, entity)
| Area | Actions |
|---|---|
| Auth | `login.success`, `login.fail` (denied), `logout` |
| Floor | `tab.open`, `tab.release` (+ denied when it still has consumption), `floor.area.create/update/delete`, `floor.table.create/update/delete` (geometry-only saves are NOT logged) |
| Reservations | `reservation.create`, `reservation.cancelled`, `reservation.no_show`, `reservation.seated` |
| Kitchen | `order.send` (+ denied: stock), `order.reprint`, `order_item.void` (+ denied), `order_item.replace` (links old line to new order; + denied) |
| Bills | `bill.create`, `bill.rename`, `bill.move_item` (+ denied), `bill.merge` (+ denied), `bill.split_equal`, `bill.undo_split` (logs the deleted children) |
| Sales / cash | `sale.checkout` (cashier = `sales.id_admin`; + denied), `cash.open`, `cash.close`, `outcome.create` |
| Catalog | `product.create/update/delete/stock_add`, `product_pack.update`, `category.create/update`, `modifier.create/update/restore/deactivate/attach`, `recipe.update` |
| Purchasing | `invoice.receive` (old/new cost, sell price and stock per line; `cost_new_cor`/`sell_new_cor` = the C$ typed, source of truth since migration 023; `cost_*`/`sell_*` are the derived dollars), `return.create`, `provider.create/update/deactivate`, `internal_use.create` |
| Ingredients | `ingredient.create/update/deactivate/reactivate/components/packs`, `ingredient.purchase`, `ingredient.receive/waste/adjustment/prepare_in/prepare_out` (per movement) |
| People/config | `employee.*`, `client.*`, `admin.create/deactivate` (security: super only), `settings.update` (one row per changed key), `exchange.update` (also re-derives every dollar price from its `*_cor` column, see CLAUDE.md C$-first), `bank_account.create/update/disable`, `goal.create`, `import.<entity>` |

Kitchen `order`/`void` ingredient movements are not duplicated (covered by `order.send` / `order_item.void`).

## Read API v1 (admin session; the Rust server must serve the same paths and shapes)
- `GET /audit/api/v1/events?action=&id_admin=&entity_type=&entity_id=&id_tab=&id_bill=&id_sale=&result=&request_id=&q=&from=YYYY-MM-DD&to=&limit=(1..500, default 50)&after=<id>&order=desc|asc`. `action` ending in `.` is a prefix (`bill.`).
- `GET /audit/api/v1/entity/{tab|bill|sale|<entity_type>}/{id}` (tab/bill/sale default to oldest first).
- Response `{"data":[event...],"next_cursor":<id|null>}`; pass `next_cursor` as `after` (keyset on `id`). Errors `{"error","message"}` with 403 (not admin), 404, 405 (only GET), 422.
- `login.*`/`admin.*` rows are visible to `super` only.
- CSV: `GET /audit/export?<same filters>` (UTF-8 BOM, formula-injection safe, max 5000 rows).

## Volume
Index set in migration 022. For years of data: archive by month (`id` ranges) to a cold table; payloads are capped. Never delete from the app.
